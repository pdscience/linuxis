Estrutura de Navegação

Como o menu deve se comportar no desktop e mobile?

A

Navbar Fixa + Hamburger Mobile

Navbar fixa no topo com blur. Hamburger menu em telas menores que 900px. Indicador de página ativa.

  • ✓ Fixa no topo sempre visível
  • ✓ Hamburger menu para mobile
  • ✓ Indicador de página ativa
  • ✓ Botão CTA "Começar Agora"
B

Navbar Fixa + Drawer Mobile

Navbar fixa. Menu lateral (drawer) desliza da esquerda no mobile com overlay escuro.

  • ✓ Fixa no topo sempre visível
  • ✓ Drawer lateral para mobile
  • ✓ Overlay escuro no fundo
  • ✓ Botão CTA "Começar Agora"
C

Navbar Scroll com Hamburger

Navbar esconde ao rolar para baixo, aparece ao rolar para cima. Hamburger no mobile.

  • ✓ Economiza espaço na tela
  • ✓ Hamburger menu para mobile
  • ✓ Aparece ao rolar para cima
  • ✓ Botão CTA "Começar Agora"
