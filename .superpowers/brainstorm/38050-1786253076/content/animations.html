Animações de Scroll

Como os elementos devem aparecer ao rolar a página?

A

Fade-in + Slide-up

Elementos aparecem com opacidade渐进 e deslizam para cima. Efeito sutil e profissional.

→
→
Opacidade: 0 → 0.6 → 1 | translateY: 20px → 10px → 0
B

Scale + Fade

Elementos crescem de 0.95 para 1.0 com opacidade. Efeito moderno e dinâmico.

→
→
Scale: 0.9 → 0.95 → 1.0 | Opacidade: 0 → 0.6 → 1
C

Sem Animações

Elementos aparecem imediatamente sem transição. Mais rápido, menos distrativo.

→
→
Sem transição - aparece imediatamente
