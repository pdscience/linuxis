Resumo das Decisões de Design

Todas as escolhas para o redesign do site LinuXis

✓

Navbar Fixa + Hamburger Mobile

Navbar fixa no topo com blur. Hamburger menu em telas menores que 900px.

✓

Grid 3 Colunas (Serviços)

3 colunas desktop → 2 tablet → 1 mobile. Cards uniformes com ícone e descrição.

✓

Footer 4 Colunas

Logo + descrição | Links rápidos | Contato | Redes sociais

✓

Contato: Formulário + Cards

Formulário à esquerda, cards de contato empilhados à direita com ícones grandes.

✓

Portfólio: Grid com Filtros

Botões de filtro no topo. Grid de cards com imagem, título e categoria.

✓

Sobre: Seções Empilhadas

Hero → Missão/Visão/Valores → Números → História → CTA

✓

Animações: Scale + Fade

Elementos crescem de 0.95 para 1.0 com opacidade ao entrar no viewport.

✓

Menu Mobile: Slide-down com Blur

Menu desliza para baixo com backdrop-filter: blur. Glassmorphism.

✓

Validação: Bordas + Mensagens Inline

Erro: borda vermelha + mensagem. Sucesso: borda verde + mensagem.
